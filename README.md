## ✨ Features & Highlights

### 🚀 1. Multi-Engine Universal Music Aggregator
- **Spotify Web API**: Top tracks, featured albums, new releases, and artist catalogs.
- **High-Precision Global Search Engine**: Instant resolution for commercial, Bollywood, South Indian (Malayalam, Tamil, Telugu, Hindi), and international hits.
- **Epidemic Sound & Jamendo**: Unlimited royalty-free music streaming and creator tracks.
- **SoundCloud Integration**: Underground, electronic, and indie discovery.

### 🔍 2. Precision Smart Search & Unlimited Browsing
- **Smart Relevance Engine**: Accurate results matching titles, movies, and artists without irrelevant fallback tracks.
- **Infinite Pagination**: Seamless unlimited scrolling across all search results, genres, and charts.
- **Multi-Language Regional Filters**: One-tap switching between Malayalam, Tamil, Hindi, Telugu, English, Punjabi, Arabic, Spanish, and more.

### 🎧 3. Audio Player & Playback Experience
- **Interactive Mini & Full-Screen Player**: Smooth drag-down gestures, seek bar, queue controls, and play/pause toggles.
- **High-Definition Audio & HD Artwork**: Automatically loads 600x600 high-res album covers.
- **Favorites & Liked Songs**: Save and manage personal music libraries locally with instant persistence.
- **Genre & Mood Explorer**: Browse Pop, Hip-Hop, Rock, Chill, Workout, Classical, and regional hits.

### 💎 4. Modern Glassmorphism UI
- Neon violet & dark navy gradient palette.
- Dynamic interactive micro-animations.
- Responsive layout optimized for mobile, tablet, and desktop viewports.

## 🛠️ Tech Stack & Architecture

- **Framework**: [Flutter](https://flutter.dev) (iOS, Android, Web, Desktop)
- **Language**: [Dart](https://dart.dev)
- **State Management**: `Provider` architecture
- **Audio Engine**: `audioplayers` / `just_audio`
- **Networking**: `http`, RESTful Multi-API aggregator
- **Image Caching**: `cached_network_image`
- **Typography & Icons**: Google Fonts, Font Awesome, Cupertino Icons

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (3.0.0 or later)
- Dart SDK
- Android Studio / Xcode / VS Code

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mohammedsajadvt/Harmoniq-Music.git
   cd "My Own Music"
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the application:**
   ```bash
   flutter run
   ```

4. **Run unit & widget tests:**
   ```bash
   flutter test
   ```
